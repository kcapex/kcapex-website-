# KCAPEX Website

A production-ready static marketing website for KCAPEX LLC, built as a GitHub Pages-ready single-page site.

## Deployment

This repo is configured for automatic deployment to GitHub Pages using a GitHub Actions workflow.

1. Go to GitHub repository settings.
2. Open Pages.
3. Set Source to "GitHub Actions".
4. Push to the `main` branch.
5. The workflow will publish the site automatically.

## Files

- `index.html` — full landing page
- `styles.css` — custom site styling
- `script.js` — mobile nav and interactive enhancements
- `.github/workflows/deploy.yml` — deployment workflow
- `.nojekyll` — disables Jekyll processing
